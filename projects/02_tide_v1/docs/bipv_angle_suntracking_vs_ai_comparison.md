## 3. 야간(태양고도 ≤ 0°) 구간 비교

추종 로직은 야간에 항상 `90°`(코드상 명시적 폴백)를 반환하지만, AI 스케줄은 야간에도 다양한 각도를 선택합니다.

| AI 최적 각도 | 타임스텝 수 | 비고 |
| ---: | ---: | :--- |
| 90° (일치) | 6,956 | — |
| 40° | 6,891 | 야간 불일치 중 최다 |
| 0° | 2,416 | |
| 10° | 2,301 | |
| 30° | 1,927 | |
| 60° | 1,531 | |
| 50° | 1,372 | |
| 70° | 1,330 | |
| 20° | 750 | |
| 80° | 729 | |

**해석(가설)**: 태양이 없는 시간대에는 발전량이 0이므로 순수 발전 관점에서는 각도가 의미 없지만, 이 플러그인의 각도 선택은 동시에 차양 투과율(Trans) 및 발전기 가용(Avail) 스케줄도 스위칭합니다(`_override_schedules`). 즉 야간에도 선택된 각도의 패널만 "불투명(차양 ON)" 상태가 되고 나머지 9개는 "투명" 상태가 되므로, 창호의 장파 복사 손실(야간 냉각) 및 익일 새벽 부하에 대비한 예열/예냉 효과가 net energy에 영향을 줄 수 있습니다. AI가 야간에 `40°`를 가장 선호하는 것은 이러한 열적 영향을 학습한 결과로 추정되나, 정확한 인과관계는 추가 검증이 필요합니다.

- **난방기(11월~5월)**: AI 각도가 추종 각도보다 **평균 +4.5°~+13.7° 높음** → 냉방기보다 적극적으로 높은 각도(패시브 솔라 획득 방향)를 선택하는 경향

이는 [`kinetic_bipv_tide_net_energy_optimization.md`](../kinetic_bipv_tide_net_energy_optimization.md) §1.1에서 서술한 "여름철엔 차양을 우선, 겨울철엔 일사 투과를 우선"하는 상충 관계 가설과 정성적으로 일치합니다.

일치율 자체도 여름(6~9월, 9.6~11.2%)이 겨울(11~2월, 28~36%)보다 훨씬 낮아, **냉방기에 AI가 태양 추종과 가장 크게 다른 전략을 취한다**는 것을 다시 보여줍니다.

## 5. 계절 대표 시간대 상세 비교 (정오~오후 1시대, 11~14시)

### 여름(6~8월) 정오~오후
- 표본 수: 2,208 타임스텝
- 추종 각도 분포: 대부분 `60°~80°` (고도각이 높아 발전 극대화 각도도 높음)
- AI 각도 분포: `10°`가 최다(1,344/2,208, 약 61%), 이어 `30°`, `40°` 순
- **평균 차이(AI−추종) = -48.3°** → 여름 한낮에는 AI가 추종보다 압도적으로 낮은 각도를 선택

### 겨울(12~2월) 정오~오후
- 표본 수: 2,160 타임스텝
- 추종 각도 분포: 대부분 `20°~50°` (고도각이 낮음)
- AI 각도 분포: `0°`가 최다(1,033/2,160, 약 48%), 이어 `30°` 순
- **평균 차이(AI−추종) = -17.0°** → 겨울 정오에도 AI는 추종보다 낮은 각도를 선호하지만, 편차 폭은 여름의 1/3 수준

두 계절 모두 정오 시간대 평균은 음수(AI < 추종)이지만, §4의 "주간 전체 평균"에서는 겨울이 양수로 나타났습니다. 이는 겨울철 아침/오후 시간대(태양고도가 낮아지는 구간)에 AI가 추종보다 오히려 높은 각도를 선택하는 경우가 많아 하루 평균을 끌어올리기 때문으로 보입니다 — 즉 겨울철에는 "정오엔 다소 낮게, 아침/저녁엔 오히려 높게" 조절하는 비대칭적 패턴이 존재할 가능성이 있습니다(후속 시간대별 세부 분석 필요).

## 8. 결론 및 후속 과제

1. **AI(TiDE) 최적 각도는 단순 태양 추종과 뚜렷이 구별되는 제어 전략이다** (연간 일치율 20% 미만).
2. **계절적 방향성이 뚜렷하다**: 냉방기엔 추종보다 낮은 각도(차양 강화 추정), 난방기 특히 아침/오후엔 추종보다 높은 각도(일사 확보 추정)를 선호하는 경향이 관측됨 — §1.1 상충 관계 가설과 정성적으로 부합.
3. **야간 제어도 발전량과 무관하게 Net Energy에 영향을 미친다**: 태양이 없는 시간대에도 AI는 90°(무차양) 대신 특정 각도(특히 40°)를 자주 선택하며, 이는 차양의 야간 열손실/복사 특성이 반영된 결과로 추정됨.
4. **후속 검증 필요 항목**:
   - 야간 각도 선택이 실제로 익일 부하(예열/예냉 효과)에 미치는 영향을 EnergyPlus로 직접 검증
   - 정오 vs 아침/저녁 시간대별 비대칭 패턴(§5)의 원인을 일사 성분비(직달/산란) 기준으로 세분화 분석
   - 두 스케줄(추종 vs AI)을 각각 실제 EnergyPlus에 주입해 연간 Net Energy 차이를 정량 비교 (Baseline 성능 확보, [`kinetic_bipv_tide_net_energy_optimization.md`](../kinetic_bipv_tide_net_energy_optimization.md) §3 2단계와 연계)
